# Atlassian Kanban - Backend

This repository contains the backend code of Atlassian's Kanban board application. 

## 🛠️ Concept involved
* **DOM**: Document Object Model
* **Express**: Fast, minimalist web framework for building the API.

## 📂 Project Structure
The project includes:
* `index.js`: The main entry point of the application.
* `middleware.js`: Custom middleware functions for handling requests and authentication.
